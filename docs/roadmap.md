# GoblinSteel — Roadmap

Five broad directions for taking the project forward, roughly in order of priority:

1. **Deepen the existing loop** — Add the three missing classes (Warrior, Cleric, Wizard), a win/loss condition, and loot drops. ✅ *Complete — see [plan-deepen-loop.md](plan-deepen-loop.md).*

2. **Expand the world** — Procedural map generation, more enemy types beyond goblins, boss encounters. The roguelike path. *Current focus — see [plan-expand-world.md](plan-expand-world.md).*

3. **Add progression / meta-game** — Between-run upgrades, a save system, unlockable classes or abilities. Shifts it toward a roguelite with replay value.

4. **Polish and juice** — Sound/music (Web Audio API), particle effects on hits, screenshake, more animation frames. The visual identity is already strong; this makes it feel finished.

5. **Multiplayer** — WebSockets for co-op or PvP. Large technical lift; the global `GS` state architecture would need a rework.
